Política de privacidad

siradig-bot es una herramienta de uso personal. Solo la usa su dueño, con su propia cuenta de Google.

Qué datos usa

Con el permiso gmail.readonly, lee los mails del usuario que contienen facturas o comprobantes, para identificar gastos deducibles de Ganancias.

Dónde se guardan

Los datos se procesan y guardan solo en la computadora del usuario. No se venden, no se comparten con terceros y no se usan para publicidad. El contenido de algunos comprobantes se envía al modelo de IA que el propio usuario contrató, solo para clasificarlos.

Cómo revocar el acceso

El usuario puede quitar el permiso en cualquier momento desde myaccount.google.com/permissions.

El uso de la información recibida de las API de Google cumple con la Política de datos del usuario de los servicios de API de Google, incluidos los requisitos de uso limitado.
